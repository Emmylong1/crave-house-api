# Crave House email OTP setup

The API is designed for a six-digit Supabase email OTP flow. The API calls `/auth/v1/otp` to request the code and `/auth/v1/verify` with `{ email, token, type: "email" }` to verify it.

## Supabase Magic Link / OTP email template

Subject:

`Your Crave House verification code`

HTML body:

```html
<h2>Verify your Crave House account</h2>
<p>Use the 6-digit verification code below to continue:</p>
<p style="font-size:32px;font-weight:700;letter-spacing:8px;">{{ .Token }}</p>
<p>This code expires shortly and can only be used once.</p>
<p>If you did not request this code, you can safely ignore this email.</p>
<p>Crave House<br>Whatever You’re Craving.</p>
```

Do not use only `{{ .ConfirmationURL }}` for this flow. That produces the Magic Link behavior shown in the previous emails.

The six-digit value must be generated by Supabase for each request; it must not be hard-coded into the API.
